# Участие в разработке HRtools

Чтобы сообщить об ошибке или предложить улучшение, выберите шаблон на странице [GitHub Issues](https://github.com/uzbatsu-beep/HRtools/issues/new/choose). Укажите версию приложения и среду, в которой проявляется проблема. Для примеров подходят вымышленные резюме и пустая тестовая база. Для вопросов безопасности используйте [закрытый канал](SECURITY.md).

Для работы с кодом установите зависимости командой `npm ci` и запустите `npm run dev`. Системные требования и команды desktop-сборки приведены в [README](README.md).

Перед pull request выполните `npm test` и `npm run build`. Для проверки импорта в браузере установите Chromium командой `npx playwright install chromium` и запустите `npm run test:e2e`. В pull request опишите изменение и укажите, как его проверили. При изменении хранения данных проверьте также восстановление копии из предыдущей версии.

В обсуждениях действует [кодекс поведения](CODE_OF_CONDUCT.md).
