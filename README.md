# HRtools — локальная рабочая станция рекрутера

HRtools помогает вести вакансии и кандидатов, оценивать компетенции и готовить оффер с планом адаптации. Данные хранятся в IndexedDB на устройстве и не синхронизируются между браузерами и приложением автоматически.

- [Веб-версия](https://uzbatsu-beep.github.io/HRtools/)
- [Репозиторий](https://github.com/uzbatsu-beep/HRtools)
- [План разработки](ROADMAP.md)
- [Как предложить изменение](CONTRIBUTING.md)

Доступны канбан и таблица кандидатов, поиск и фильтры, конструктор вакансий, скоркарты и сравнение кандидатов, аналитика, CSV-экспорт, досье и черновики офферов. AI-разбор требует отдельно настроенного совместимого сервера модели; перед отправкой резюме проверяйте указанный адрес сервера.

## Данные и резервные копии

Используйте экспорт JSON для резервного копирования: в нём сохраняются вакансии, кандидаты и сохранённые черновики офферов. Восстановление **заменяет** текущие данные; перед ним сохраните актуальную копию. CSV предназначен для просмотра в электронных таблицах, а не для восстановления базы. Файлы резервных копий содержат персональные данные — храните их в защищённом месте.

Данные браузера могут быть удалены при очистке данных сайта или изменении профиля. Приложение не гарантирует возможность первого запуска веб-версии без сети: для работы сайта сначала необходимо загрузить его ресурсы. Desktop-версия хранит данные отдельно от веб-версии.

## Разработка

Требуется Node.js 20.19+ или 22.12+ и npm. Для сборки desktop-версии также необходимы инструменты Rust и системные зависимости Tauri.

```bash
npm ci
npm test
npm run dev
npm run build
```

Сервер разработки доступен только на локальном интерфейсе. Для сборки desktop-приложения используйте `npm run tauri -- build`.
