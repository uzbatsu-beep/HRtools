# HRtools — Local-First Offline HR Workstation

Автономная рабочая станция для технических рекрутеров, HRBP и нанимающих инженеров. Работает полностью офлайн в браузере или как нативное `.exe` приложение.

- **Web-демо (GitHub Pages):** `https://uzbatsu-beep.github.io/HRtools/`
- **Репозиторий:** `https://github.com/uzbatsu-beep/HRtools`

## Модули внутри:
1. **Сорсинг и Boolean / X-Ray Генератор** (пресеты АСУ ТП / ПЛК, Python Backend, QA Automation)
2. **Мини-ATS и Regex-парсер резюме** (автоизвлечение контактов, стека и подсчет Stage Aging)
3. **Интерактивные скоркарты STAR** с весовыми коэффициентами компетенций
4. **Калькулятор стоимости замены сотрудника (Turnover Cost)** и **Compa-Ratio**
5. **Генератор офферов и планов адаптации 30-60-90**

## Локальный запуск
```bash
npm install
npm run dev
```
