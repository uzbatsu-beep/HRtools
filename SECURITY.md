# Сообщить об уязвимости

Отправьте сообщение сопровождающему через [закрытую форму GitHub Security Advisories](https://github.com/uzbatsu-beep/HRtools/security/advisories/new). Укажите версию HRtools, операционную систему, среду запуска и наблюдаемое влияние на данные или работу приложения.

Используйте вымышленные данные и удалите из вложений контакты кандидатов, тексты настоящих резюме и учётные данные. Переписка об исправлении будет доступна в закрытом отчёте.
